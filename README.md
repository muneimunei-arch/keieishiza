# 茨城の経営者の視座を高める会

公開用に編集した活動ログと募集案内です。原文メールと添付ファイルは含めません。

## 更新

`content.json` を編集して `npm run build` を実行します。次回の日時は `dist/index.html` の参加案内も更新してください。

リポジトリのルートで `git pull --ff-only`、編集後に `git add .`、`git commit -m "活動記録を更新"`、`git push` を実行します。VercelとのGit連携により main の更新を自動公開します。

## Vercel

Root Directory: リポジトリのルート。Framework: Other。Build Command: `npm run build`。Output Directory: `dist`。

募集用メール窓口のみ本人の承認に基づき掲載しています。活動ログは呼び名だけに統一し、メール原文の転載は行いません。
